# Statistical Decision Theory

Учебный репозиторий по теории статистических решений: конспекты, реализации алгоритмов, эксперименты на реальных датасетах.

## О чём репозиторий

Здесь собираются материалы по ключевым разделам теории статистических решений — от базовых понятий (функция потерь, риск, решающие правила) до прикладных методов (байесовские классификаторы, минимаксные стратегии, оценка параметров). Каждая тема сопровождается теорией и кодом на Python.

## Темы

- Функции потерь и риска (0-1, квадратичная, асимметричная)
- Байесовский риск и байесовское решающее правило
- Минимаксный подход и критерий Вальда
- Оценка параметров: MLE, MAP, байесовские оценки
- Проверка гипотез как задача принятия решений
- Линейный и квадратичный дискриминантный анализ
- Наивный байесовский классификатор
- Связь с машинным обучением: регуляризация, ансамбли, калибровка
